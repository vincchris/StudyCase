# 🚀 Problem Solving Journey (JavaScript & Python)

Welcome to my **Problem Solving Journey** repository!

This repository contains coding challenges that I solve using **JavaScript** and **Python** to improve my programming logic and problem-solving skills.

The challenges start from beginner-friendly problems and gradually become more difficult, helping me build a strong foundation before moving on to more advanced algorithms and data structures.

* Improve logical thinking
* Strengthen problem-solving skills

## 📋 Challenge Format

Every challenge follows the same structure.

```javascript
/*
Challenge 01: Positive or Negative

Determine whether a given number is positive,
negative, or zero.

Example:
Input: -5

Output:
Negative
*/
```

Each solution focuses on solving the problem using basic programming concepts before relying on built-in functions.

## 📚 Rules

* Solve every challenge without looking at the solution first.
* Focus on understanding the logic, not memorizing code.
* Complete the JavaScript solution before translating it into Python.
* Avoid using built-in methods when the goal is to practice algorithms.
* Refactor the solution after it works.
